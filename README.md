## Featured Projects

### 01 / AgentGuard

**An AI security gateway for agentic workflows**

`Python` `Ollama` `LangChain` `ChromaDB` `RAG` `Streamlit`

A local AI security gateway and simulated SOC investigation environment. The goal is to explore what happens when an AI agent can access tools and how those actions can be controlled.

What I built:

- An AI Investigator Agent for analyzing simulated security events.
- Policy checks before allowing agent tool execution.
- Restrictions for unauthorized tools and sensitive-file access.
- ChromaDB-based retrieval of MITRE ATT&CK, OWASP and security playbook knowledge.
- Investigation traces, security testing and audit logging.

**Engineering focus:** Agent security, tool permissions, retrieval pipelines and traceability.

### 02 / PartnerTax.AI

**An AI copilot for tax and compliance research**

`Python` `FastAPI` `AWS Bedrock` `RAG` `PostgreSQL` `React`

 An AI-powered research application focused on U.S. tax and compliance information.

 What I built:

- Managed RAG workflows with AWS Bedrock Knowledge Bases.
- IRS-focused knowledge retrieval.
- Retrieval controls and response guardrails.
- FastAPI backend services.
- AWS Cognito authentication and PostgreSQL integration.
- React-based application workflows.

**Engineering focus:**  Managed RAG, cloud integration and source-grounded AI responses.

### 03 / Cybercrime Classification

**Machine learning for cybersecurity activity analysis**

`Python` `Pandas` `Scikit-learn` `TensorFlow`

An academic machine learning project using a cybersecurity activity dataset to distinguish normal and suspicious behavior.

What I worked on:

- Analyzed 7,400 records.
- Performed data preprocessing and feature selection.
- Compared Random Forest and neural network approaches.
- Evaluated model performance using classification metrics suitable for imbalanced data.

**Engineering focus:** Data preparation, feature selection, classification and model evaluation.
